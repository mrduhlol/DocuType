# DocuType Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a Manifest V3 Chrome extension that reveals a practice passage character by character in a floating Google Docs panel, with pause, resume, restart, stop, and approximate progress.

**Architecture:** A popup validates the active Docs tab and injects five small classic scripts on demand (`activeTab` + `scripting`). A testable `TypingEngine` schedules the reveal; a Shadow-DOM panel renders it; `content.js` wires messages and enforces one live session at a time. No background worker, storage, network calls, or dependencies.

**Tech Stack:** Chrome Manifest V3, HTML, CSS, vanilla JavaScript (classic scripts), Node 22+ built-in test runner, Chromium for browser harness tests.

**Spec:** `docs/superpowers/specs/2026-10-19-docutype-design.md`

## Global Constraints

- Chrome Manifest V3; no external dependencies, build step, remote fonts, or network requests.
- Permissions: `activeTab` and `scripting` only.
- Work only on `https://docs.google.com/document/...` document URLs.
- Never enter text into, read, or modify the Google Docs editor.
- Never store or transmit the passage.
- Popup pace presets: Gentle 30 WPM, Steady 45 WPM, Quick 65 WPM.
- Passage limit: 10,000 Unicode code points.
- Progress is approximate and based on prompt reveal, never verified typing.
- UI must support light and dark environments and reduced motion.

## Review Focus

- Repeated starts must not duplicate panels, message listeners, button handlers, or timers.
- Pause/resume/restart/stop must be safe when clicked rapidly, at the final character, or after completion.
- Non-Docs, discarded, restricted, and navigated-away tabs must produce clear errors without partial UI.
- Passages with newlines, whitespace-only input, and emoji must render and count correctly.
- The popup and panel must remain legible in light and dark themes, and the panel must be insulated from Google Docs CSS.
